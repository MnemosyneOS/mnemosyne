**Mnemosyne OS 8.1.0** — ゼロ依存（サードパーティライブラリ不要）、ローカル優先の AI 記憶システムです。多層型忘却（忘却の経済学）、ハッシュチェーン台帳、プラグイン SDK、ローカル Web ダッシュボード、および MCP（Model Context Protocol／モデルコンテキストプロトコル）に対応しています。

> コアが**サードパーティの依存関係を一切必要としない**唯一の AI 記憶エンジンです（Python 標準ライブラリ 3.8+ のみに依存）。ベクトルデータベース不要、LLM（大規模言語モデル）ランタイム不要、クラウドへのロックインもありません。ノート PC、サーバー、サーバーレス基盤のいずれでも動作します。

**Python ライブラリ**、**CLI（コマンドライン）**、**HTTP API**、**MCP サーバー**として利用できるほか、**MCP（モデルコンテキストプロトコル）** の stdio トランスポート経由で組み込むこともできます。

<tr><td><b>多層型メモリ</b></td><td>ホット／ウォーム／コールドの階層と「忘却の経済学」を備え、低価値な記憶は移行し、決して黙って削除されることはありません。</td></tr>

## はじめに

### CLI（コマンドライン）

```bash
# Initialize the memory database
python mnemosyne.py --dir ./mem init

# Store a memory
python mnemosyne.py --dir ./mem retain --content "Apple Inc. was founded in 1976"

# Search memories
python mnemosyne.py --dir ./mem recall "Apple" --k 5

# Consolidate similar memories (pre-check)
python mnemosyne.py --dir ./mem consolidate --dry-run

# View status / health check
python mnemosyne.py --dir ./mem status --json
python mnemosyne.py --dir ./mem doctor --json

# Knowledge graph query
python mnemosyne.py --dir ./mem graph-query "Steve Jobs" --depth 2 --json

# Ledger integrity / audit
python mnemosyne.py --dir ./mem verify-integrity --json
python mnemosyne.py --dir ./mem ledger-audit <memory_id>

# Export / import
python mnemosyne.py --dir ./mem export --format json --out ./memories.json
python mnemosyne.py --dir ./mem import ./memories.json

# Migrate JSONL -> SQLite
python mnemosyne.py --dir ./mem migrate --jsonl ./mem/index.jsonl

# Start the web dashboard
python -m mnemosyne.webui.web_server --port 9090
```

### Python API

```python
from mnemosyne import MemoryBrain

brain = MemoryBrain("./my_memories", enable_embeddings=False)
brain.ensure_init()

# Store
brain.retain("Apple Inc. was founded in 1976", fast=True)

# Recall
results = brain.recall("Apple", k=5)
for score, record, reasons in results:
    print(f"Score: {score:.4f} | {record['content']}")

# Token-budgeted recall
results, cost_report = brain.recall("Apple", k=5, budget_tokens=100)

# Conversation history
brain.add_conversation_turn("session-1", "user", "Tell me about Apple")
hits = brain.search_conversations("Apple", session_id="session-1")

# Context snapshot
snapshot = brain.build_context_prompt(query="Apple", max_chars=2000)
```

### 非同期 API

```python
import asyncio
from plugins.async_wrapper import AsyncMemoryBrain

async def main():
    brain = AsyncMemoryBrain("./memories", enable_embeddings=False)
    await brain.async_retain("Hello World", fast=True)
    results = await brain.async_recall("Hello", k=5)
    print(results)
    brain.close()

asyncio.run(main())
```

### MCP サーバー

MCP サーバーを stdio 経由の JSON-RPC（標準 JSON-RPC トランスポート）で起動します：

```bash
export MNEMOSYNE_MCP_TOKEN="your-secret-token"   # optional token auth
python -m mnemosyne.webui.mcp_server --brain-dir ./mem --namespace default
```

MCP サーバーは **55 のツール** を提供します：

| Tool | Description |
| --- | --- |
| `retain` | 記憶を書き込む |
| `recall` | 記憶を検索する |
| `retain_batch` | 一括書き込み（約15倍高速） |
| `stats` | 実行時統計 — 書き込み数／検索数／トークン節約量 |
| `graph_query` | ナレッジグラフ検索 |
| `temporal_query` | 時系列バージョン連鎖検索 |
| `list_projects` | 分離されたプロジェクト一覧 |
| `doctor` | ヘルスチェック — 整合性・レコード数・ディスク |
| `audit` | 監査証跡の検索 |
| `confidence_history` | 信頼度の軌跡検索 |
| `memory/export-v1` | Memory Exchange Protocol 経由のエクスポート |
| `memory/import-v1` | Memory Exchange Protocol 経由のインポート |
| `memory/claim` | 外部エクスポートからの記憶の取得 |
| `memory_export-v1` | `memory/export-v1` の別名（ツール名に `/` を使えないクライアント向け） |
| `memory_import-v1` | `memory/import-v1` の別名（ツール名に `/` を使えないクライアント向け） |
| `memory_claim` | `memory/claim` の別名（ツール名に `/` を使えないクライアント向け） |
| `forget` | 記憶を忘却 — 信頼度を 0 にしてソフト削除 (`memory_id`、または自然言語の `query` を受け付け) |
| `consolidate` | 圧縮エンジン・記憶統合 — 高度に類似／同義の記憶を集約し 1 件の代表記憶に統合、元の記憶は `consolidated` としてマーク（`min_similarity` / `max_group` / `generate_summary` / `dry_run`） |
| `reflect` | 圧縮エンジン・拡張リフレクション — 記憶の総量、タイプ／層／ファクト種別／信頼度分布、頻出エンティティ、ファクト矛盾の検出、時系列密度を集計；`deep=true` で認知パターン発見を追加 |
| `dedup` | 圧縮エンジン・重複排除 — 内容フィンガープリント＋ベクトル／語頻度類似度で重複・近似重複を検出；`dry_run=true` は報告のみ |
| `recall_health` | 召回品質メトリクス（読み取り専用）— 空結果率、top1 の推移、関連性下限による除去数、レイテンシ |
| `capsule` | 記憶をポインタ＋事実＋原子に圧縮 — 無損失でアドレス可能 |
| `expand` | カプセルの原文を逐字取得（ハッシュ検証付き） |
| `session_summarize` | セッション要約 — 7 要素（目標 / 制約 / 決定 / 未決 / 成果物 / 失敗 / 偏好） |
| `session_recall` | セッションまたはプロジェクト別に要約と未決事項を呼び戻す |
| `conflict_resolve` | 衝突の分類と解消（6 クラス、まず `dry_run`） |
| `task_record` | タスク事実の記録 — 何をしてどうなったか（事実層） |
| `playbook_save` | 経験の保存 — **前提条件は必須**（must / must_not / typical_env） |
| `playbook_recall` | 目標タイプ + 前提条件で経験を検索し `applicable` / `blocked_by` を返す |
| `code_change_record` | コード変更イベントの記録（意図 / 制約 / 却下した案） |
| `code_archaeology` | ファイルやシンボルの変更履歴と落とし穴を遡って引く |
| `memory_policy` | 感度レベルとソースポリシーの参照 / 設定 |
| `profile_card` | ユーザープロフィールカード — 三段（安定したアイデンティティ / 設定と制約 / 現在の状況）+ 未決事項。system prompt にそのまま連結可能 |
| `memory_inject` | コンテキスト注入パイプライン：クエリ構築 → 四路召回 → RRF 融合 → リランク → 予算内注入 |
| `recall_catalog` | 漸進的開示・カタログ層：タイトル + 一言 + 展開コストのみ返却（本文は返さない） |
| `expand_memory` | 漸進的開示・展開：本文 + 統一エンベロープ + グラフ近傍 + 証拠チェーン |
| `memory_envelope` | 統一メモリエンベロープ：八クラス分類 + 四次元スコープ + 証拠チェーン + 二時間軸 + TTL + SPO |
| `memory_consolidate` | 三つの統合パス：エピソード→セマンティック、エピソード→手続き、失敗→負の記憶（冪等） |
| `memory_metrics` | 指標：Chat (5) + Working (4) + Coding (4)。データ不足は 0 ではなく `insufficient_data` を返す |
| `memory_cascade_delete` | カスケード削除：原本をソフト削除 → 派生結論を失効 → キャッシュ削除 → 依存要約を stale に |
| `memory_mask` | マスク：本文をプレースホルダに置換しつつレコード骨格を保持（KV-Cache 再利用を壊さない） |
| `topic_summarize` | L3 テーマ要約：同一 project の複数の L2 セッション要約を統合 |
| `memory_trace` | ポインタチェーン遡及：L3→L2→L1、各層の内容と対象ターン・`message_ids` を返却 |
| `memory_hot_path` | ホットパスバッファ：`enable` で非同期書き込み、`status` でキュー確認、`flush` で書き込み完了待ち |
| `add_memory` | ユーザー/エージェントのためにテキストや会話を保存 |
| `search_memories` | フィルタ付き意味検索 |
| `get_memories` | 構造化フィルタ + ページング一覧 |
| `get_memory` | id で 1 件取得 |
| `update_memory` | テキストと/またはメタデータを上書き |
| `delete_memory` | 1 件削除 |
| `delete_all_memories` | スコープを空にする |
| `delete_entities` | エンティティをカスケード削除 |
| `list_entities` | users/agents/apps/runs を一覧 |
| `list_events` | 記憶操作を一覧 |
| `get_event_status` | 非同期操作をポーリング |

上記の stdio コマンドを指定することで、どの MCP ホスト（Claude Desktop、Hermes Agent など）からでも接続できます。

### HTTP API（Web 管理界面）

```bash
python -m mnemosyne.webui.web_server --port 9090
```

その後 `http://127.0.0.1:9090` を開くと、記憶の閲覧・グラフ表示・統計に加え REST（Representational State Transfer）エンドポイントを備えたローカル暗色ダッシュボードが表示されます。デフォルトアカウント `admin / mnemosyne` は初回起動時に作成されます。ログイン後はパスワードを変更してください。

## プラグイン

```python
# Crypto plugin (requires cryptography; degrades gracefully otherwise)
brain = MemoryBrain("./memories", plugins=["crypto"])

# Numpy vector backend (requires numpy; optional sentence-transformers model)
brain = MemoryBrain("./memories", plugins=["numpy_vector"])

# Reranker plugin
brain = MemoryBrain("./memories", plugins=["reranker"])
```

## プロジェクト構成

```
Mnemosyne8.1.0/
├── mnemosyne.py              # Thin facade re-exporting the mnemosyne package
├── mnemosyne/                # Core engine package (brain / storage / retrieval / cognitive / notary)
├── storage/                  # Storage backends (sqlite_backend / ledger / session_store / plugin_sdk)
├── context/                  # Context snapshots (snapshot_builder)
├── context_engine/           # Context compression engine (engine-agnostic core + Hermes adapter)
├── lexical/                  # Built-in synonym dictionary
├── profiles/                 # User profile management
├── providers/                # External provider adapter + multi-source router
├── security/                 # Contradiction detection + security report
├── session/                  # Conversation importer
├── visualization/            # Knowledge tree generator
├── plugins/                  # Extra plugins (HRR / Async)
├── mnemosyne_plugins/        # Official plugins (numpy_vector / crypto / reranker / qdrant_backend)
├── examples/                 # Runnable examples (Ollama / LangChain / MCP / CLI / embedded)
└── docs/                     # Documentation (architecture, modules, plugins, API, deployment)
```
