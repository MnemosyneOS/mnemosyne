## 四、引擎核心特性

| 特性 | 说明 |
|------|------|
| 多语言支持 | 中文·English·日本語·한국어·Français·Deutsch·Español·Русский 等 30+ 语言 |
| 倒排索引 | BM25 检索 O(n)→O(log n)，11ms/recall |
| TF向量缓存 | 免重复分词，检索加速 25× |
| 五路融合检索 | BM25+随机投影+知识图谱+时间衰减+可信度 |
| Cross Encoder Hybrid | 多维特征重排序（保留原始检索+追加新评分） |
| Multi-Hop推理 | 实体链式推理图扩展 |
| 框架无关 | Hermes/OpenClaw/LangChain/AutoGPT/CrewAI 等全兼容 |
| 零依赖 | 纯 Python 标准库，JSONL+图+倒排索引 |
