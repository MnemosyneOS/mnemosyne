**Mnemosyne OS 8.1.0** — 외부 의존성 없는(zero-dependency), 로컬 우선(local-first) AI 기억 시스템입니다. 다단계 망각(multi-tier forgetting), 해시 체인 원장(hash-chain ledger), 플러그인 SDK(plugin SDK), 로컬 웹 대시보드(local web dashboard), 그리고 MCP(Model Context Protocol / 모델 컨텍스트 프로토콜)를 지원합니다.

> **핵심이 외부 서드파티 의존성 없이 동작하는** 유일한 AI 기억 엔진입니다(Python 표준 라이브러리 3.8+만 의존). 벡터 데이터베이스, LLM(대형 언어 모델) 런타임, 클라우드 종속성이 필요 없습니다. 노트북, 서버, 서버리스 인프라에서 모두 실행됩니다.

**Python 라이브러리**, **CLI(명령줄)**, **HTTP API**, **MCP 서버**, 또는 **MCP** stdio 전송을 통해 임베드하여 사용할 수 있습니다.

## 시작하기

### CLI

```bash
# Initialize the memory database
python mnemosyne.py --dir ./mem init

# Store a memory
python mnemosyne.py --dir ./mem retain --content "Apple Inc. was founded in 1976"

# Search memories
python mnemosyne.py --dir ./mem recall "Apple" --k 5

# Consolidate similar memories (pre-check)
python mnemosyne.py --dir ./mem consolidate --dry-run

# View status / health check
python mnemosyne.py --dir ./mem status --json
python mnemosyne.py --dir ./mem doctor --json

# Knowledge graph query
python mnemosyne.py --dir ./mem graph-query "Steve Jobs" --depth 2 --json

# Ledger integrity / audit
python mnemosyne.py --dir ./mem verify-integrity --json
python mnemosyne.py --dir ./mem ledger-audit <memory_id>

# Export / import
python mnemosyne.py --dir ./mem export --format json --out ./memories.json
python mnemosyne.py --dir ./mem import ./memories.json

# Migrate JSONL -> SQLite
python mnemosyne.py --dir ./mem migrate --jsonl ./mem/index.jsonl

# Start the web dashboard
python -m mnemosyne.webui.web_server --port 9090
```

### Python API

```python
from mnemosyne import MemoryBrain

brain = MemoryBrain("./my_memories", enable_embeddings=False)
brain.ensure_init()

# Store
brain.retain("Apple Inc. was founded in 1976", fast=True)

# Recall
results = brain.recall("Apple", k=5)
for score, record, reasons in results:
    print(f"Score: {score:.4f} | {record['content']}")

# Token-budgeted recall
results, cost_report = brain.recall("Apple", k=5, budget_tokens=100)

# Conversation history
brain.add_conversation_turn("session-1", "user", "Tell me about Apple")
hits = brain.search_conversations("Apple", session_id="session-1")

# Context snapshot
snapshot = brain.build_context_prompt(query="Apple", max_chars=2000)
```

### 비동기 API

```python
import asyncio
from plugins.async_wrapper import AsyncMemoryBrain

async def main():
    brain = AsyncMemoryBrain("./memories", enable_embeddings=False)
    await brain.async_retain("Hello World", fast=True)
    results = await brain.async_recall("Hello", k=5)
    print(results)
    brain.close()

asyncio.run(main())
```

### MCP 서버

MCP 서버를 stdio JSON-RPC(표준 JSON-RPC 전송)로 실행합니다:

```bash
export MNEMOSYNE_MCP_TOKEN="your-secret-token"   # optional token auth
python -m mnemosyne.webui.mcp_server --brain-dir ./mem --namespace default
```

MCP 서버는 **55개 도구**를 제공합니다:

| 도구 | 설명 |
| --- | --- |
| `retain` | 기억을 저장합니다. |
| `recall` | 기억을 검색합니다. |
| `retain_batch` | 일괄 저장, 약 15배 속도 향상. |
| `stats` | 런타임 통계 — 쓰기 / 검색 / 토큰 절감. |
| `graph_query` | 지식 그래프 쿼리. |
| `temporal_query` | 시계열 버전 체인 쿼리. |
| `list_projects` | 격리된 프로젝트 목록. |
| `doctor` | 상태 점검 — 무결성, 레코드 수, 디스크. |
| `audit` | 감사 추적 쿼리. |
| `confidence_history` | 신뢰도 궤적 쿼리. |
| `memory/export-v1` | 메모리 교환 프로토콜을 통한 내보내기. |
| `memory/import-v1` | 메모리 교환 프로토콜을 통한 가져오기. |
| `memory/claim` | 외부 내보내기에서 기억 가져오기. |
| `memory_export-v1` | `memory/export-v1` 의 별칭 ("/"를 허용하지 않는 클라이언트용) |
| `memory_import-v1` | `memory/import-v1` 의 별칭 ("/"를 허용하지 않는 클라이언트용) |
| `memory_claim` | `memory/claim` 의 별칭 ("/"를 허용하지 않는 클라이언트용) |
| `forget` | 기억 하나를 잊기 — 신뢰도를 0으로 설정하고 소프트 삭제 (`memory_id` 또는 자연어 `query` 허용) |
| `consolidate` | 압축 엔진·기억 통합 — 매우 유사/동의어 기억을 하나의 대표 기억으로 병합하고 원본은 `consolidated`로 표시 (`min_similarity`, `max_group`, `generate_summary`, `dry_run`) |
| `reflect` | 압축 엔진·강화 성찰 — 총량, 유형/계층/사실 유형/신뢰도 분포, 상위 엔티티, 사실 충돌 탐지, 시간 밀도를 집계; `deep=true`는 인지 패턴 발견 추가 |
| `dedup` | 압축 엔진·중복 제거 — 내용 지문 + 벡터/단어빈도 유사도로 중복 및 근사 중복 탐지; `dry_run=true`는 보고만 |
| `recall_health` | 검색 품질 지표(읽기 전용) — 빈 결과율, top1 추이, 관련성 하한으로 제거된 수, 지연 |
| `capsule` | 기억을 포인터+사실+원자로 압축 — 무손실이며 주소 지정 가능 |
| `expand` | 캡슐의 원문을 글자 단위로 복원(해시 검증 포함) |
| `session_summarize` | 세션 요약 — 7요소(목표 / 제약 / 결정 / 미결 / 산출물 / 실패 / 선호) |
| `session_recall` | 세션 또는 프로젝트별로 요약과 미결 항목을 재호출 |
| `conflict_resolve` | 충돌 분류 및 해소(6类, `dry_run` 우선) |
| `task_record` | 작업 사실 기록 — 무엇을 했고 결과가 어땠는지(사실 계층) |
| `playbook_save` | 경험 저장 — **전제 조건은 필수**(must / must_not / typical_env) |
| `playbook_recall` | 목표 유형 + 전제 조건으로 경험을 검색해 `applicable` / `blocked_by` 반환 |
| `code_change_record` | 코드 변경 이벤트 기록(의도 / 제약 / 기각한 접근법) |
| `code_archaeology` | 파일이나 심볼의 변경 이력과 함정을 거슬러 추적 |
| `memory_policy` | 민감도 등급과 출처 정책 조회 / 설정 |
| `profile_card` | 사용자 프로필 카드 — 세 단계(안정적 정체성 / 선호와 제약 / 현재 상황) + 미해결 항목, system prompt에 바로 연결 가능 |
| `memory_inject` | 컨텍스트 주입 파이프라인: 쿼리 구성 → 4경로 검색 → RRF 융합 → 리랭크 → 예산 내 주입 |
| `recall_catalog` | 점진적 공개·카탈로그 계층: 제목 + 한 줄 + 확장 비용만 반환(본문은 반환하지 않음) |
| `expand_memory` | 점진적 공개·확장: 본문 + 통일 봉투 + 그래프 이웃 + 증거 체인 |
| `memory_envelope` | 통일 메모리 봉투: 8개 분류 + 4차원 scope + 증거 체인 + 이중 시간축 + TTL + SPO |
| `memory_consolidate` | 세 가지 통합 경로: 에피소딕→의미, 에피소딕→절차, 실패→부정 기억(멱등) |
| `memory_metrics` | 지표: Chat (5) + Working (4) + Coding (4). 데이터 부족 시 0 대신 `insufficient_data` 반환 |
| `memory_cascade_delete` | 캐스케이드 삭제: 원본 소프트 삭제 → 파생 결론 무효화 → 캐시 정리 → 의존 요약 stale 표시 |
| `memory_mask` | 마스크: 본문을 플레이스홀더로 교체하되 레코드 골격은 유지(KV-Cache 재사용 유지) |
| `topic_summarize` | L3 주제 요약: 같은 project의 여러 L2 세션 요약을 통합 |
| `memory_trace` | 포인터 체인 역추적: L3→L2→L1, 각 층의 내용과 대상 턴·`message_ids` 반환 |
| `memory_hot_path` | 핫 패스 버퍼: `enable` 비동기 쓰기, `status` 큐 확인, `flush` 쓰기 완료 대기 |
| `add_memory` | 사용자/에이전트를 위해 텍스트나 대화를 저장 |
| `search_memories` | 필터가 있는 시맨틱 검색 |
| `get_memories` | 구조화된 필터 + 페이지 목록 |
| `get_memory` | id로 1건 조회 |
| `update_memory` | 텍스트와/또는 메타데이터 덮어쓰기 |
| `delete_memory` | 1건 삭제 |
| `delete_all_memories` | 스코프 비우기 |
| `delete_entities` | 엔티티를 연쇄 삭제 |
| `list_entities` | users/agents/apps/runs 목록 |
| `list_events` | 기억 작업 목록 |
| `get_event_status` | 비동기 작업 폴링 |

위 stdio 명령을 가리키도록 설정하여 모든 MCP 호스트(Claude Desktop, Hermes Agent 등)에 연결하세요.

### HTTP API (웹 대시보드)

```bash
python -m mnemosyne.webui.web_server --port 9090
```

그런 다음 `http://127.0.0.1:9090`을 열면 메모리 탐색, 그래프 보기, 통계, REST 엔드포인트를 갖춘 로컬 다크 대시보드가 나타납니다. 기본 계정 `admin / mnemosyne`은 최초 실행 시 생성되며, 로그인 후 비밀번호를 변경하세요.
